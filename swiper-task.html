任务一 · 提示词工程师不写代码，写出提示词 · 两轮迭代 · 亲自验证（★★）

需求翻译给 AI，让它生成 new Swiper('#wySw4', {...}) 配置：① 无缝循环 ② 3.2 秒自动翻页且手动操作后不停 ③ 圆点分页器可点击 ④ 初始效果为 cube。以下保留每轮提示词与 AI 回答，并已亲自粘贴到本页验证。

第 1 轮提示词（宽松表达，留下了遗漏点）

提示词："帮我写一个 Swiper 的配置，要求：循环播放、自动播放、圆点分页器、默认用 cube 立方体效果，用 new Swiper('#wySw4', {...}) 的写法。"

AI 回答要点：

new Swiper('#wySw4', {
  loop: true,
  autoplay: true,
  effect: 'cube',
  pagination: { el: '#wyPag4' }
})

亲自验证发现的问题：① autoplay 用开关写法，速度是默认 3000ms，不是要求的 3.2 秒；② 没写 disableOnInteraction: false，手动拖一下自动播放就停了；③ 分页器没写 clickable: true，圆点点了没反应。

第 2 轮提示词（把每条需求编号并写明参数名）

提示词："重新写 new Swiper('#wySw4', {...}) 的配置对象，逐条满足并直接写出对应参数名：① loop: true 无缝循环；② autoplay 里 delay: 3200（3.2 秒）、disableOnInteraction: false（用户拖动后自动播放继续）；③ pagination 用 el: '#wyPag4' 且 clickable: true；④ effect: 'cube'，切换动画 speed: 800。只输出配置对象，不要解释。"

AI 回答：与演示四实际初始化代码一致（见页面底部脚本），粘贴到本页后逐条复验全部通过，即当前页面正在运行的配置。

任务二 · creative 仿写：课堂没讲，AI 教你第 7 种效果 · 电影选片墙（★★★★★ 6 分）

已为演示四新增第 7 个按钮「creative 电影字幕」（见上方按钮组）。配合官方示例 swiper/demo/257-effect-creative.html 与 AI 读懂 creativeEffect 的 transform 写法后，实现：上一张向左上收带倾角、下一张大幅右移进场，切换如电影选片墙。

与 AI 的关键对话（提示词 + 回答）

提示词："我读了 Swiper 官方示例 257-effect-creative.html，还是不懂 creativeEffect 里 prev / next 的 transform 结构。用一句话讲清楚它各控制哪张图，再给一份'上一张往左上收带点角度、下一张从右侧大幅进来'的配置。"

AI 回答要点：prev 控制"正在退场的前一张"、next 控制"即将进场的后一张"；每张是一个 transform 描述：translate 三轴位移、rotate 三轴旋转、scale 缩放、shadow 投影，数值随切换进度在 0 → 设定值 之间渐变。据此给出下方配置，粘贴实测即"电影选片墙"效果。

本页实际采用的配置：

creativeEffect: {
  limitProgress: 2,
  prev: { shadow: true, translate: ['-118%', '-10%', -180], rotate: [0, 0, -12] },
  next: { shadow: true, translate: ['118%', '8%', -180], rotate: [0, 0, 12] }
}

任务三 · 综合创作第六件展品 + 课堂外新能力 parallax 视差（★★★）

① 第六件展品「爱达·魔都号」（首艘国产大型邮轮，2024 年 1 月首航）已加入全部四个演示台：图片为 AI 生成的 16:9 横版图，slide 结构与其它展品一致（图片 + 渐变字幕说明）。② 新能力选用 parallax 视差：演示四每张 slide 的图片加了 data-swiper-parallax-scale、字幕加了 data-swiper-parallax 与 data-swiper-parallax-opacity，配置开启 parallax: true —— 切换时图片微微放大、字幕以相反方向滞后移动并渐显，画面出现"远近两层"的纵深感。

与 AI 的关键对话记录（提示词 + 重要往返）

提示词："Swiper 11 想给演示四加 parallax 视差：切换时字幕比图片移动得慢一点、有前后层次感，怎么写配置？"

AI 第一次回答：只给了一句 parallax: true —— 粘贴到本页后字幕纹丝不动，毫无视差效果。

追问 & 修正："加了 parallax: true 为什么没效果？"AI 补充：parallax 只是总开关，真正生效的是 slide 内部元素上的 data-swiper-parallax（位移量）、data-swiper-parallax-scale（缩放）、data-swiper-parallax-opacity（透明度）属性——元素没打标记，引擎就不会动它。给字幕加 data-swiper-parallax="-45%" 和 data-swiper-parallax-opacity="0"、图片加 data-swiper-parallax-scale="1.12" 后，视差效果出现。

新参数的作用：parallax: true 开启视差引擎，随切换进度驱动所有带标记的元素；-45% 表示字幕以图片相反方向、45% 的幅度滞后移动（负号 = 反向）；scale: 1.12 让图片在切换中轻微放大再回弹，营造"镜头推拉"感；opacity: 0 让字幕从透明渐显到清晰。

把 delay 改成"递进渐变"的预期变化：autoplay 的 delay 只接受固定数值，若让每张停留时间逐次 +500ms，页面会"越翻越慢、先快后慢"；由于 delay 不会自动递变，需要监听 slideChange 事件动态调整，或停用 autoplay 后用 setTimeout 自行调度。
