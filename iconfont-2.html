肆 / NOTES

原理笔记

<script src="cdn/lucide/lucide.min.js"></script>

<i data-lucide="feather"></ilucide.createIcons();

/* SVG 属性可被 CSS 直接覆盖 */
svg { stroke-width: 1.5; color: #d65c42; }

SVG 方式的本质：Lucide 提供 JavaScript 库，扫描页面上的 data-lucide 占位元素，把真正的 <svg> 路径注入 DOM。

与字体图标的差别：SVG 是矢量图形而非字体字符，stroke-width（线宽）可以独立调整，多色、渐变、局部变形都成为可能。

着色机制：路径描边使用 stroke="currentColor"，跟随文字 color 变化，一枚图标即可融入任何配色。
